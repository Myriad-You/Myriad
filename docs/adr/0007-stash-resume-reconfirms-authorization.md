# 暂存实例恢复前重新确认授权前提

Status: accepted

暂存实例在离场期间保留了授予权限与会话令牌。恢复时不能假设暂存期间世界静止——配置可能被改、令牌可能过期、授权前提可能已经消失。销毁路径没有这个问题，因为重建会完整走一遍授权。

决定：恢复暂存实例前，重新走一遍授权确认——授予权限按当前角色与动态配置重算、会话令牌过期则重签、代码指纹或登录态变化则不再恢复而改为销毁。**授权前提消失时，恢复退化为销毁**，绝不带着过期授权原样复活。

## Consequences

恢复路径引入一次额外的授权复核，是「隐藏替代销毁」能成立的安全前提——没有这步，「看不见却活着」的实例就可能带着已失效的授权继续运行。

「可见出口」的配套可见性（后台存活实例的可见与单独停掉）由 ADR 0005 定义，此处不重复。
