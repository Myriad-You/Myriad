# Triage Labels

The engineering skills use five canonical triage roles.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be implemented |

For local Markdown tickets, record the value near the top of the file:

`Status: ready-for-agent`
