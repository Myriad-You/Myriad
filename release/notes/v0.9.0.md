本次更新汇总 `v0.8.0` 之后的多端协议升级与设备能力、统一记忆节点、Agent 面板与设置诊断、形象手势以及基础设施调整。

- 跨设备与 XR 端就绪：设备链接统一升级至协议 2 与共享核心 ABI 6（`log6`），新增连接能力自报与版本比对（`versions`、`link.versions` / `link.verdict`），设备页可查看各端版本是否落后、超前或不齐；放开 `notify.post`、`voice.speak`、`work.run` 统一调用与设备分组批准，支持消息附带图片（`images`）及 `streams` 可靠事件流与拒绝原因计数。
- 统一记忆节点：她的长期记忆全面改走节点（新增 `memory_nodes`、主题指向、遗忘标记、私聊消息向量、说过的话等数据表，旧话题表不再读写）；站长可在「记忆 → 节点」页按受众查看节点、记忆、经历与意图，并改名、删除单条或整节点、取消意图；同步开关开启时，设备端私聊与「说过的话」及底层状态可随她的日志与快照同步。
- Agent 面板与设置体验：私聊支持她发送卡片并在网页与设备端作答；站内文字聊天改为聊天软件式的拆条、正在输入状态与已读/表情回应；访客打开 Agent 面板时可在输入框实时搜索站内已发布笔记与资料库（仅搜索、不提问）；「与电脑同步」开关默认关闭且开启前须阅读确认说明；Agent 设置新增站长可见的「她现在活着吗」状态诊断与停摆/模型连续无响应告警。
- 形象、媒体与站点：半身与全身形象支持三维手势手臂生成与说话抬手；博客新增服务端站内搜索与正文中单行音视频链接自动播放器，贴入/导入笔记的外站图片自动转存本站，同一实例两用户的联邦私信拆分为每人一行；媒体库支持一次多选及拖拽批量上传；升级 `ammonia`、`cookie`、`url` 等依赖修复已公布漏洞。
- 稳定性与界面修复：修复 `motion_overlay` 取消时的崩溃隐患，并收整深色模式与面板样式细节；修复局域网 HTTP 下缺失 `randomUUID` 导致的白屏、Steam 锁区游戏封面、官方 QQ 群聊与 Discord 机器人消息监听选项。
- 基础设施调整：`proxy` 为 `/api/merope/rig` 与 `/api/agent/persona` 单独延长超时至 18 分钟以覆盖长耗时生图与拆层；`updater` 同步更新依赖锁文件。

**破坏性变更与升级提示**：设备链接自本版本起不再接受协议 1 的旧端连接，连接端应用需同步升级；本次包含 6 个新增数据库 SQL 迁移脚本及租约/联邦私信表结构调整，**升级前请务必在更新界面完成完整数据库备份**。

本次发布 backend、frontend、proxy、updater `v0.9.0` 镜像。
