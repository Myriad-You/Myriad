本次更新汇总 `v0.7.1` 之后的多端记忆同步、Agent 办事、形象与站点修复。

- 站点参与节点同步：她在 Mac 和站点之间的记忆节点、忘掉的内容和身份可以互相接上，换设备后接得上之前的事。
- 私聊和网页面板都能把几件事同时交给助手，每件可查、可补充、可叫停；重启后接着办，确认题答序号或 yes 也认，没开始的不再显示成办完。
- 帮手带回的结果按帮手的话交给她，回想、记一天和主动开口时都不再算成她自己说过的话。
- 她自己没想通的问题，会想去问懂这个的人；设备端说话时可以附带给她看的图片。
- 2.5D 形象搬成独立模块；修复转头时的嘴形、侧发和刘海、耳朵与耳饰、脖颈、帽子分层和全身站姿，调整笑眼弧度。
- 从别的博客搬来的文章，旧地址 301 跳到新文章页。
- 修复笔记表格与块工具条、创作台深色下拉、提示被遮住、图片扩展名与格式不符时拒收、Steam 老封面 404、配置页网站地址显示与图标上传超限。
- 做事任务的 token 预算提到 1M；站长在还没有报告时也能生成第一份平台报告。
- Guard token 校验在非 C locale 下正常，出错时说明原因和重新生成的办法；follow-redirects 升到 1.16.2。

本次发布 backend、frontend、proxy `v0.8.0` 镜像。updater 没有代码变更，继续使用 `v0.7.0`，不重新发布。数据库有迁移（节点同步用的表），更新前请按更新界面的提示完整备份。
